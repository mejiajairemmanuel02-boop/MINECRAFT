# MINECRAFT

Página web simple para la comunidad **Ballakos Craft**.

## Mejoras aplicadas
- Estructura HTML semántica (`header`, `main`, `section`, `footer`).
- Estilos modernos y responsive con tema oscuro/claro.
- Interactividad con JavaScript para:
  - Mostrar estado dinámico del servidor.
  - Cambiar tema con un botón.

## Uso
1. Abre `index.html` en tu navegador.
2. Haz clic en **Cambiar tema** para alternar la apariencia.
